# Metric — aplicativo financeiro offline

Base de implementação Flutter para Android/iOS, seguindo os relatórios de produto, engenharia e design fornecidos.

## Executar

```bash
flutter pub get
flutter analyze
flutter test
flutter run
```

> Verificado: `flutter analyze`, `flutter test` (19 passando) e `flutter build apk --debug` (APK gerado em build/app/outputs/flutter-apk/app-debug.apk).

Leia `IMPLEMENTACAO.md` para a matriz de requisitos, escopo entregue e pendências críticas de segurança.
